# The Modernest Gulch View

A modern, responsive short-term rental website built for **The Modernest**, designed to give guests a polished and user-friendly way to explore the property, view amenities, browse gallery images, and book their stay.

## Live Demo

[View Live Site](https://themodernestgulchview.vercel.app/)

## Overview

**The Modernest Gulch View** is a Next.js web application created for a luxury short-term rental property. The site focuses on clean visual design, smooth user interaction, and an elegant guest experience.

The design highlights modern luxury through large imagery, refined typography, subtle animations, and an easy-to-use navigation structure.

## Features

- Responsive layout for desktop, tablet, and mobile
- Modern luxury-inspired landing page
- Gallery section showcasing property and location imagery
- Smooth animations powered by GSAP
- Clean navigation for key guest actions
- “Book Now” call-to-action
- User-friendly structure for short-term rental guests
- Deployed with Vercel

## Tech Stack

- **Next.js** – React framework for building the web application
- **Tailwind CSS** – Utility-first CSS framework for styling
- **GSAP** – Animation library for smooth motion effects
- **Vercel** – Hosting and deployment

## Installation

To run this project locally, clone the repository and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the project in your browser:

```bash
http://localhost:3000
```

## Project Goals

The goal of this project was to create a professional, high-end website for a short-term rental brand that feels visually polished while remaining simple for guests to use.

The site was designed with a focus on:

- Strong first impression
- Clean visual hierarchy
- Easy guest navigation
- Property-focused imagery
- Smooth, modern animations
- Clear booking path
